# 咕嘟 · Gudu v0.1.0

发布日期：2026-11-10

给自己，一杯水的时间。

咕嘟是一个原生 macOS 喝水提醒应用：跟着你的工作屏幕，在忙碌之间留出一点喝水的时间。

- **新安装默认**：45 分钟、周一至周五 09:00–18:30、工作屏幕，摄像头检测开启，音效和自动退场关闭；已有保存设置不覆盖。
- **按自己的节奏**：提醒间隔、每日时段与每周提醒日自由设置，支持跨午夜。
- **豆豆陪你喝水**：开放式厨房接水、举杯、喝水与惬意舒气的完整矢量动画；可关闭音效，完成后有庆典撒花。
- **适应多屏**：跟随鼠标所在屏幕，也可选择全部屏幕。
- **合盖回来也记得**：未过点保留时间，错过后恢复并缓冲 30 秒只补一次；距下一正常提醒不超过 5 分钟就跳过补提醒。
- **可选本机摄像头识别（实验性）**：记住嘴部位置，累计 3 秒有效杯具线索完成；遮脸或漏检保留进度，手部辅助按半速累计。新安装默认开启，未授权或摄像头不可用时支持手动确认；应用启动和普通动画预览不启用摄像头。
- **保持轻巧**：菜单栏常驻、可选登录启动、当天饮水统计；无账号、无广告、无追踪、完全离线。

## 支持与附件

仅支持 Apple Silicon（arm64，M 系列芯片）和 macOS 14+。不包含 Intel 版本；其他 macOS 版本仍需各自验证。

| 附件 | 状态与用途 |
| --- | --- |
| `Gudu-0.1.0-macos-arm64-unsigned.zip` | 完全未签名、未公证；Apple Silicon 运行前需自行添加本地 ad-hoc 签名 |
| `Gudu-0.1.0-macos-arm64-unsigned.zip.sha256` | 上述压缩包的 SHA-256 |

没有使用公司的账号或开发者证书。安装与首次打开步骤见 [安装指南](https://github.com/xcoderliu/Gudu/blob/main/docs/INSTALL.md)。Gatekeeper 可能拦截未公证应用；只有核对来源和校验和后才允许打开。

摄像头功能识别嘴边杯具，不能确认实际吞咽或饮水量；水量按预设的一杯记录。画面不保存、不上传。先用「测试摄像头识别」验证自己的杯子、握法与光线。
