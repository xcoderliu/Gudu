## 界面与素材检查

已在运行的应用中检查主界面、提醒设置、饮水记录与撤销、间隔预设、跟随鼠标模式、所有屏幕模式、预览、Esc 退出、预览完成和自动退场。预览完成后没有增加饮水记录。

人物选项已移除，当前统一使用豆豆小人。开放式厨房场景、豆豆小人的接水 / 喝水 / 放松姿态，以及设置界面，使用实际源视图离线导出进行视觉检查；另导出 15 秒完整动作 GIF 与拿杯六帧对照图。配图使用隔离的示例数据，不包含真实饮水记录。旧人物字段兼容测试覆盖三个旧枚举值、未知字符串、对象与 null，均保留其他偏好，重新编码不包含人物字段。

摄像头功能的设置界面与强制提醒界面使用源视图进行了离线渲染检查，没有启动真实摄像头或保存真实画面。Vision Revision 1 的六个杯具标签通过系统 API 查询确认，同时确认没有单独的 `paper_cup` 类别。纯逻辑测试不等同于真实识别准确率；授权弹窗、摄像头占用、纸杯、透明杯、不同光线和角度尚需通过「测试摄像头识别」实测。因此当前版本保留默认关闭。

用户实测反馈旧版存在“杯子在脸旁易通过、正常喝水遮挡面部反而漏检”，并进一步指出丢失人脸时进度仍会回退。本次按反馈改为保留最后一次可靠嘴部位置，取消丢脸超时，并使杯具漏检只暂停进度；同时实际裁出附近区域后再分类。新版真实摄像头准确率仍待用户复测，未将逻辑测试当作准确率证明。

用户进一步确认高失败率发生在普通无柄纸杯。本次增加杯口与倾斜裁剪、多处较弱杯具线索结合嘴边手部位置的慢速路径，以及测试模式的分数 / 分类显示；没有添加纸杯专用模型。新增回归测试约束算法行为，真实纸杯的成功率仍待用户在实际握法和光线下复测。

音频资源已确认是可读取的 PCM WAV，主音轨 15 秒、完成声 1.1 秒。音效来自项目的离线合成脚本。听感、个人舒适音量和长时间重复播放体验仍建议维护者实际试听调整。

界面自动化在部分操作中返回了窗口不可用或界面变化，未把这些结果认定为用户主动中断；因此没有把未完成的窗口触发观察、硬件逐屏确认或系统场景检查标为通过。实际 Timer 与状态流已通过上述独立集成检查。
